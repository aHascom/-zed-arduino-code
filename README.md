# Zed Arduino Code

## 📌 Wat is dit?

Dit project laat je Arduino code schrijven en uploaden via de Zed editor.
Je kunt automatisch of handmatig libraries zoeken en gebruiken.

⚠️ Let op: je moet Arduino CLI geïnstalleerd hebben.

---

## 🧰 Wat heb je nodig?

* Een Arduino board (maakt niet uit welke, bijvoorbeeld Uno, Nano, etc.)
* Zed editor
* Arduino CLI

---

## ⚙️ Installatie

1. Installeer Arduino CLI
2. Open Zed
3. Ga naar Extensions
4. Installeer de "Dev Extension"
5. Druk op `Ctrl + Shift + P`
6. Kies **Task: Spawn**

---

## 🚀 Code uploaden

1. Druk op `Ctrl + Shift + P`
2. Kies opnieuw **Task: Spawn**
3. Selecteer **Upload**

---

## 📚 Libraries

Je hebt twee opties:

* Automatisch zoeken
* Handmatig toevoegen

Het systeem probeert automatisch de juiste instellingen en pins te detecteren.

---

## 🔌 Pins

Je kunt zelf kiezen welke pins je gebruikt.
Het systeem helpt automatisch bij het instellen.
